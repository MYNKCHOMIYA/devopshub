# DevOpsHub

DevOpsHub is a production-style task management platform built as a practical
DevOps learning project.

The application provides basic task-management functionality while the primary
engineering focus is on building, deploying, securing, monitoring, and operating
the platform using real-world DevOps practices.

## Project Goals

DevOpsHub will progressively cover:

- Linux administration
- Bash scripting
- Git and GitHub
- Networking
- Nginx
- HTTPS/TLS
- React
- FastAPI
- PostgreSQL
- Redis
- Docker
- Docker Compose
- GitHub Actions
- CI/CD
- AWS
- Terraform
- Monitoring and logging
- Prometheus
- Grafana
- Loki
- Kubernetes
- AWS EKS
- Security
- Scaling
- Deployment strategies
- Backup and disaster recovery
- Production troubleshooting

## Application

DevOpsHub is a task-management application supporting:

- User registration
- Authentication
- Projects
- Tasks
- Task status
- Task priority
- Comments
- Activity logs
